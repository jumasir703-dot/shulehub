Import books from a file

Upload a CSV or Excel (.xlsx) list of your books. The first row must have headings. Only Title is required; the others are used when present: Author, ISBN, Publisher, Year, Edition, Category, Subject, Shelf, Price, Copies (how many you own, default 1) and Accession (your own accession numbers, only if you already have them).

  • Copies get numbered automatically (LIB-00001, LIB-00002…) unless you supply accession numbers.
  • A row with the same ISBN, or the same title and author, as a book you already have adds copies to it instead of creating a duplicate.
  • The import is all-or-nothing: if something goes wrong, nothing is added. Rows with a problem are skipped and listed afterwards.
